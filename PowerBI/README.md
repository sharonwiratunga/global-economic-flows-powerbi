# Power BI Dashboard

This folder contains the Power BI dashboard developed for analysing global economic flows.

## Dashboard Focus

The dashboard analyses:

- Global Trade
- Foreign Direct Investment (FDI)
- Official Development Assistance (ODA)
- Remittances
- Private Capital

## Analysis Areas

The dashboard provides:

- Executive-level overview
- Country and regional comparisons
- Trade and investment analysis
- Long-term economic flow trends
- Year-over-year growth analysis
- Moving-average trend analysis
- Indicator comparisons across decades
- Country-level rankings

## Main Dashboard Pages

1. Executive Overview
2. Country & Regional Analysis
3. Trade & Investment Insights
4. Trends & Comparisons

## Main Technologies

- Microsoft Power BI
- DAX
- Data modelling
- Data visualisation
- Interactive slicers
- KPI cards
- Trend analysis

## Source

United Nations Development Programme (UNDP) – Trade and investment flow data accessed via Kaggle.

Data year: 2019.
